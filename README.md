# Учебный стенд «Управление вагонным парком»

Автономный экспорт для тестирования от 09.11.2026. Четыре модуля, основные задачи и задачи с дополнительными условиями, глоссарии и видеозаглушки.

## На компьютере Windows

1. Полностью распакуйте ZIP в отдельную папку.
2. Откройте index.html в Chrome или Edge. Можно также запустить start-windows.bat.
3. Для полноэкранного просмотра нажмите F11, для выхода — F11 ещё раз.

Для этой копии не нужны ChatGPT, интернет, установка Node.js или сборка. Не открывайте страницу прямо из ZIP: сначала извлеките все файлы.

## Локальный сервер (при необходимости)

Если браузер ограничивает локальные файлы и на компьютере установлен Python 3, откройте терминал в папке стенда и выполните:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

На Windows вместо python можно использовать py. Откройте http://127.0.0.1:4173/ . Для остановки — Ctrl+C. Сервер доступен только на этом компьютере.
Для постоянной установки в BM Aura настройка автозапуска и проверка браузера выполняются отдельно на устройстве.

## GitHub Pages

Создайте репозиторий и загрузите содержимое папки в его корень: index.html должен находиться в корне, а не внутри ZIP или дополнительной вложенной папки.
В Settings → Pages выберите Deploy from a branch, ветку main и каталог / (root). Сохраните и дождитесь публикации. Адрес сайта появится в разделе Pages.
Если Pages недоступен, проверьте его доступность для вашего типа репозитория и тарифного плана. Публичный репозиторий открывает исходный код; доступ к сайту на GitHub не наследует закрытый доступ версии в ChatGPT.
Все пути в стенде относительные, сборка не требуется. Файл .nojekyll включён.

## Состав

- index.html — входная страница.
- style.css — оформление.
- app.js — задачи, схемы, расчёты и интерфейс.
- config.js — пути к четырём видео.
- media/ — папка будущих роликов.
- start-windows.bat — запуск в браузере Windows.
- validate.cjs — необязательная проверка расчётов, нужен Node.js.

## Видео

Готовых роликов в архиве нет. Заглушки сохранены. Положите MP4-файлы в media/ и измените config.js:

```js
window.STAND_VIDEOS = [
  'media/M1_intro.mp4',
  'media/M2_intro.mp4',
  'media/M3_intro.mp4',
  'media/M4_intro.mp4'
];
```

До подключения роликов все задания работают.

## Учебный сеанс

Ответы сохраняются при переходах между модулями и сбрасываются при перезагрузке страницы. На главном экране доступны разделы «О ЦО» и «О стенде». Каждый модуль содержит глоссарий. Видеозаглушки сохранены.

Нет внешних шрифтов, аналитики, CDN и сетевых API. Исходники доступны для дальнейшего редактирования.

## Проверка

При наличии Node.js выполните в папке стенда:

```sh
node --check app.js
node validate.cjs
```

Проверены восемь экранов задач, варианты назначения, ограничения сроков и пригодности, все десять комбинаций отправления поездов. Интерфейс проверен в облачном Chromium. На физическом стенде с BM Aura ещё требуется проверка масштаба, касаний, видео и длительной работы.

Логотипы РУТ и ЦО кликабельны и открывают информационные разделы. Готовые видео пока не включены. Служебные данные облачного хостинга, учётные данные и история Git в экспорт не включены.

Режим бездействия: 5 минут + предупреждение 30 секунд. Изменение интервалов — STAND_KIOSK в config.js. Возврат очищает ответы и прогресс.
